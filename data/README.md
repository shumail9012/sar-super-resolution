# Data

The full dataset (66 JERS-1 SAR GeoTIFF mosaics, ≈1.8 GB) is not stored in this repository.

Download it from the ORNL DAAC: **JERS-1 Synthetic Aperture Radar, 100-m Mosaics, South America: 1995–1996**
https://doi.org/10.3334/ORNLDAAC/1280

Place the `.tif` files directly in this `data/` folder. `sample/MOSAIC_130.tif` is included so you can test the pipeline without downloading everything.
